# 01 — Problem Statement

## The Core Problem

Arghyadeep manages simultaneously:
- KIIT coursework (attendance-critical, 75% minimum)
- AD agency operations
- AI projects for career growth
- ML engineering placement prep
- Karpathy playlist (transformer architecture)

These exist in separate silos. No system has the full picture. Cognitive overhead consumes time that should go toward building.

## What Exists Today — And What It Fails At

| Tool | What It Does | What It Fails At |
|------|-------------|-----------------|
| Claude.ai | Answers questions | No memory, dies when tab closes |
| Google Calendar | Stores events | Never warns proactively, no KIIT integration |
| GitHub | Stores code | Never auto-commits, never reviews |
| KIIT Portal | Shows attendance | No alerts, must be checked manually |
| WhatsApp | Communication | Requires full attention, no triage |
| Obsidian | Knowledge storage | Passive — never reads itself, never acts |

## The Gap

No system exists that:
1. Perceives context continuously without being asked
2. Acts on behalf of the owner within rules he controls
3. Learns from outcomes and changes behaviour
4. Gets smarter from the accumulation of shared history

## The Solution — VECTOR

VECTOR is a continuously running autonomous AI presence. Perceives all inputs (voice, camera, screen, phone, calendar, health). Understands goals hierarchically. Acts through zero-trust permissions. Evolves through reinforcement learning.

**Not a chatbot. Infrastructure for Arghyadeep's entire working life.**

| Without VECTOR | With VECTOR |
|---------------|-------------|

| Miss GitHub commits, lose context | Auto-commits with meaningful messages daily |
| Miss SaaS opportunities while sleeping | Scans Reddit/HN nightly, validates by morning |
| Reply to 30 messages manually | Drafts replies in Arghyadeep's voice per relationship |
