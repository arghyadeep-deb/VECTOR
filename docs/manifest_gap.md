# Manifest Gap Report

Generated by `scripts/manifest_gap.py` — static AST scan of `districts/*/` diffed against `config/agent_manifest.yaml`. A class counts as a real agent if it subclasses `AgentBase` or defines its own `run`/`async run` method (covers orchestrator classes like `OpsSwarm`/`QASwarm` that don't subclass `AgentBase`).

`run() branches?` is a heuristic (looks for `"type"`/`'type'` literals inside the run method's AST) — a hardcoded-output agent (e.g. ignores params) will show `no` and should NOT be registered as-is without a follow-up fix; it will fake-succeed once dispatched regardless of task type.

**Totals: 86 registered / 26 swarm-reachable / 85 unregistered / 197 real agent classes found.**

`__init__ needs args?` = `yes` means `ManifestLoader.instantiate_all()`'s bare `cls()` call will fail; needs an adapter or default args before registering.

## Triage (manual pass, 2026-06-21, updated after registering coding_swarm/finance_swarm/research_swarm)

Of the 85 still-unregistered classes:

- **33 ready to register as-is** — own `run(task)`, branches on `task["type"]`, zero-arg `__init__`.
- **42 need a run()-branching fix first** — have a `run()` that takes `task` but doesn't appear to look at `task["type"]` (stock_analyst-style). Registering as-is repeats the exact bug class this effort exists to close, one level down.
- **1 needs an adapter** — `districts.startups._base.StartupAgentBase`: abstract base class, exclude.
- **9 have no `run()` of their own** — mostly correctly-wired elsewhere (`EmergencyResponseSystem` started directly by `autonomous_loop.py:1766`, `SubconsciousLoop` wired via `cron_jobs.py`'s interval job) or need a real `run()` written.

(15 of the original 114 were `ops`/`qa` swarm sub-agents already excluded in the first triage pass; the scanner now detects this pattern automatically — `_swarm_self_loaded_qualified_names()` — and an additional 26 turned out to be `coding`/`finance`/`research` swarm sub-agents once `coding_swarm`/`finance_swarm`/`research_swarm` were registered as their districts' front door, same pattern as `ops_swarm`/`qa_swarm`.)

**Governor fallback note (2026-06-21):** Task A.3 was implemented per spec as an "honest miss" (no run + no HP when no agent declares the task_type as a capability) but reverted after verification against real call sites — `core/api/routers/*.py` dispatches 100+ specific task_type strings (e.g. `db_optimize`, `budget_analyze`, `list_expenses`) that don't literally appear in any agent's `capabilities` list (those tags are descriptive themes, not a controlled vocabulary synced to every real caller). The honest miss broke most sampled real dispatches. Shipped instead: keep the HP-pick fallback running (availability preserved), withhold the +50 HP award when the winning agent wasn't actually capability-matched (Darwinian signal still protected). See `core/city/governor.py` dispatch().
