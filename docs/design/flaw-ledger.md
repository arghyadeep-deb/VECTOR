# VECTOR flaw ledger

**Status:** living ledger

This ledger is the durable, evidence-backed list of currently known flaws,
blockers, and acceptance gaps for the staged repository-closure work. It
consolidates the current truth from:

- [`capability-closure-matrix.md`](capability-closure-matrix.md)
- [`gap-register.md`](gap-register.md)
- the staged-closure plans under [`../superpowers/plans/`](../superpowers/plans/)
- the approved staged-closure design and latest verification context

This is not a claim that the repository is complete. It is a living ledger and
**must be updated after each verification**: add new findings, update evidence
and next actions, and change status only when the stated exit criteria are
met. `DONE` means the specific flaw or classification has current proof; it
does not imply that every adjacent capability is complete.

Status values used here are `OPEN`, `IN_PROGRESS`, `DONE`, and `BLOCKED`.

## Update rule

After every verification run, update the affected row in this file before
describing the capability as closed, live, or accepted elsewhere. Include the
command or test artifact, the observed result, the date/context when useful,
and the next action or exit evidence. A passing import, static scan, friendly
message, or raw `ok` field is not sufficient proof of a live capability.
