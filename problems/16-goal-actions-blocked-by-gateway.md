# Problem 16 — Goal-Generated Actions Always Blocked by Gateway

**Severity: HIGH**
**Status: DOCUMENTED — requires adding action types to gateway**
**Discovered: 2026-05-11 by 6-agent codebase audit**

## Symptom

Every action generated by `goal_system.generate_immediate_actions()` is
classified as `UNKNOWN` by `permission_gateway.py` and silently blocked.
VECTOR's goal-driven behavior loop produces actions that never execute.

## Root Cause

`goal_system.py` generates action type strings:

| Horizon | Generated action type |
|---------|----------------------|
| SHORT | `"progress_g_daily_commit"` |
| SHORT | `"progress_g_karpathy_30"` |
| LONG/MID kickstart | `"kickstart_g_vector_phase1"` |
| LONG/MID kickstart | `"kickstart_g_placement_prep"` |

`permission_gateway.py` classifies by checking against its GREEN/YELLOW/RED
lists. None of the above action strings appear in any list. They fall through
to the `UNKNOWN` branch which blocks execution without logging (or logs only
at debug level).

## Secondary Issue

`goal_system.generate_immediate_actions()` only generates kickstart actions
for goals with `progress == 0.0` exactly. Any goal with recorded progress
(even 1%) is excluded. Pre-seeded goal `g_vector_phase1` has `progress: 0.25`
and is therefore permanently excluded from generating actions.

Fix condition: `progress < 1.0` instead of `progress == 0.0`.

## Fix Required

### Part 1 — Add goal action types to permission gateway

`core/loop/permission_gateway.py`:

```python
GREEN = [
    "read_calendar", "play_music", "search_web", "check_weather",
    "check_attendance", "take_screenshot", "set_timer",
    # Goal system actions
    "progress_goal",    # records progress toward a goal
    "kickstart_goal",   # logs a kickstart attempt for a stalled goal
]

YELLOW = [
    "send_message_routine", "create_calendar_event",
    "commit_code", "download_file", "set_reminder",
]
```

And update goal_system to use these canonical action types:

```python
# Instead of f"progress_{goal['id']}"
action_type = "progress_goal"
params = {"goal_id": goal["id"], "goal_name": goal["name"]}
```

### Part 2 — Fix progress threshold in goal_system.py

```python
# Before
if goal.get("progress", 0) == 0.0:

# After
if goal.get("progress", 0) < 1.0:
```
